수치가 빈 후보는 계산하지 않습니다. 분기별 설정입니다. 변경 시 후보 점수와 수급 시나리오가 즉시 다시 계산됩니다.

아래 초기값은 도구 사용을 위한 가상 가정입니다. MSCI의 공식 편입 기준이나 실제 추종자금 규모가 아닙니다.

분기별 시나리오 설정

추종 AUM은 동일 지수를 추종하는 중복 없는 자금만 입력하세요. 복제 비율은 실제 해당 주식을 매수할 것으로 가정하는 비율입니다. 단순 시총 × 유통비율은 MSCI FIF와 다를 수 있습니다.

KRX Open API 연결

GitHub Actions가 등록된 KRX_API_KEY Secret으로 종가를 조회합니다. 이 화면은 마지막으로 검증된 종가 자료를 읽습니다. 인증키는 화면·브라우저 저장소·백업에 포함되지 않습니다.

필요한 서비스: 유가증권 일별매매정보 / 코스닥 일별매매정보. 인증키 및 이용 승인 안내 ↗

데이터 가져오기 & 백업

CSV 템플릿을 채워 분기별 후보를 가져오세요. JSON 백업은 모든 분기·설정·체크리스트를 포함합니다.

저장은 현재 브라우저에 한정됩니다. 브라우저 데이터 삭제나 다른 기기로 이동하기 전에 백업하세요. KRX 종가는 GitHub Actions 실행 후 갱신 버튼으로 불러옵니다. 기본 실행 시각은 평일 18:10 KST이며 실행이 지연될 수 있습니다. 일별 종가 API이므로 실시간 시세·MSCI FIF·편입확률을 제공하지 않습니다. 종가·시총·평균 거래대금·20거래일 수익률은 KRX에서 갱신합니다. 파일만 열면 저장 종가와 CSV 갱신을 사용할 수 있습니다.

RESEARCH FRAMEWORK

편입 가능성과 수급 수혜를 함께.

공식 방법론을 확인하고, 일관된 가정으로 우선 검토 대상을 정합니다.

01 / 먼저 투자 가능성을 확인합니다

MSCI GIMI는 시가총액, 유통주식 조정 시가총액, 유동성, 외국인 투자 가능성 등 여러 요건을 고려합니다. 이 도구는 공식 방법론 전체를 재현하지 않습니다. ATVR·거래 빈도 및 외국인 투자 가능성·상장 이력 등 기타 요건을 직접 확인한 뒤 각 항목을 ‘통과’로 기록하세요. 미확인 항목이 있으면 우선 후보로 분류하지 않습니다.

02 / 사용자 정의 점수로 비교합니다

점수 = 규모 30 + 유통시총 30 + 수급 강도 20 + 선반영 억제 20 (총 100점). 규모 점수는 min(시총 ÷ 가정 기준 ÷ 1.5, 1) × 30, 유통시총도 동일하게 계산합니다. 수급 점수는 min(max(순유입 ÷ 일평균 거래대금, 0) ÷ 3, 1) × 20입니다. 선반영 점수는 max(0, 20 − max(20거래일 수익률, 0) × 0.5)입니다. 모든 계산 수치가 입력되고 각 시총 가정 기준 이상, 확인 항목 모두 통과, 순유입 양수, 점수 70 이상이면 ‘우선 검토’입니다.

이 점수는 검증된 편입 확률이나 기대수익률이 아닙니다. 가정 기준은 공식 컷오프가 아니며 시장별 범위·버퍼·규모 구간·기존 구성종목 처리 등에 따라 실제 결과가 달라집니다. 점수는 소수점 원값으로 판단하고 화면에 반올림합니다.

03 / 수급을 시나리오로 계산합니다

예상 순유입(억원) = 추종 AUM(억원) × (변경 후 비중 − 현재 비중, bp) ÷ 10,000 × 복제 비율(%)/100. 두 비중은 반드시 AUM에 사용한 동일 지수 기준으로 입력합니다. 신규 편입 검토는 현재 비중을 0으로 입력하세요. 수급 강도는 예상 순유입 ÷ 20거래일 일평균 거래대금이며 거래일 배수입니다. 동일 종목의 다른 지수 노출은 중복 계산하지 않습니다.

04 / 매분기 반복할 순서

① 리뷰 분기 선택 → ② 최신 구성종목과 시장 데이터 확보 → ③ 후보 입력 또는 CSV 업로드 → ④ 시총 기준과 AUM 등 가정 조정 → ⑤ 공식 요건 확인 → ⑥ 관심 후보 선정 → ⑦ 발표 후 결과 기록 → ⑧ 다음 분기로 복사 후 시세·유동성·비중 재확인. 복사된 후보의 확인 항목은 ‘미확인’으로 되돌립니다.
